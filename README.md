# InstaD

Android-приложение для скачивания видео (Reels) из Instagram на телефон — с последующей пересылкой в Telegram, WhatsApp и куда угодно.

**Скачать последнюю версию:** https://github.com/incub42-spec/InstaD/releases/latest → файл `InstaD-x.y.z.apk`

---

## Установка

1. Откройте на телефоне страницу [Releases](https://github.com/incub42-spec/InstaD/releases/latest) и скачайте файл `InstaD-x.y.z.apk` (~98 МБ — внутри Python, yt-dlp и ffmpeg, которые делают всю работу прямо на телефоне).
2. Откройте скачанный файл. Android спросит разрешение на установку из неизвестных источников — разрешите для браузера или файлового менеджера, из которого открываете APK. Это стандартно для любого приложения не из магазина.
3. Нажмите «Установить». Готово — иконка InstaD появится в списке приложений.

Требования: Android 7.0 и новее. Обновление на новую версию ставится поверх старой, ничего удалять не нужно.

## Как пользоваться

### Основной способ — «Поделиться» из Instagram

1. В Instagram откройте нужный ролик.
2. Нажмите самолётик (иконка «Отправить»).
3. В нижнем ряду выберите **«Поделиться»** (не контакт, а именно кнопку со стрелкой).
4. В системном меню выберите **InstaD** (может быть на второй странице списка приложений; после первого раза Android будет показывать его среди недавних).
5. InstaD откроется и сразу начнёт скачивание. Через несколько секунд появится надпись «Готово! Видео сохранено в галерею» и превью ролика.

### Вручную

Скопируйте ссылку на ролик, откройте InstaD, вставьте её в поле и нажмите «Скачать».

### Что дальше

- **Превью** на экране «Готово» — тап по нему открывает видео в галерее.
- **«Поделиться»** — отправить скачанное в Telegram, WhatsApp или любое другое приложение.
- Все скачанные файлы лежат в галерее в альбоме **InstaD** (папка `DCIM/InstaD`).
- **«Мои загрузки»** (кнопка внизу главного экрана) — сетка всего скачанного: тап — открыть, долгое нажатие — поделиться или удалить.

### Вход в Instagram

Часть роликов Instagram не отдаёт без авторизации. Если скачивание падает с ошибкой вроде «login required» или «rate-limit reached» — нажмите **«Войти в Instagram»** внизу главного экрана и войдите в свой аккаунт. После этого внизу будет надпись «Instagram: вход выполнен», и такие ролики начнут скачиваться. Вход хранится только на вашем телефоне.

## Если не работает

| Что видите | Что делать |
|---|---|
| `[Errno 101] Network is unreachable` | Приложение не может выйти в интернет — обычно из-за VPN. Если ваш VPN пропускает через себя только выбранные приложения (split tunneling, «раздельное туннелирование»), добавьте InstaD в его список. |
| `login required` / `rate-limit reached` | Войдите в Instagram через кнопку внизу главного экрана (см. выше). |
| `There is no video in this post` / `No video formats found` | Это пост с фотографиями, а не видео. В текущей версии фото не скачиваются. |
| Скачивание началось само при открытии приложения | Обновитесь до 1.0.2 или новее — это было исправлено. |
| Нижние кнопки не видны в маленьком окне | Обновитесь до 1.0.1 или новее — экран стал прокручиваться. |

## О качестве видео

Скачивается лучший «единый» файл, который отдаёт Instagram: **720p, H.264 + AAC** — он воспроизводится везде и без проблем пересылается в мессенджеры. Instagram также отдаёт 1080p, но только в кодеке VP9 раздельными потоками; такой файл хуже дружит с галереей и чужими телефонами. Учтите: при отправке *как видео* Telegram и WhatsApp пережимают ролик сами; чтобы получатель увидел оригинальное качество, отправляйте *как файл*.

## Для разработчиков

### Как устроено

- Kotlin, экраны: главный, «Мои загрузки», WebView-вход в Instagram.
- Движок — [youtubedl-android](https://github.com/yausername/youtubedl-android) (yt-dlp + Python, работающие на телефоне), артефакты `library` и `ffmpeg` с Maven Central.
- Встроенный yt-dlp сам обновляется до ночной сборки не чаще раза в сутки — так приложение переживает изменения на стороне Instagram.
- Cookies после входа экспортируются в формат Netscape и передаются yt-dlp через `--cookies`.
- Формат yt-dlp — `b/bv*+ba/best`: сначала готовый единый файл (H.264+AAC), склейка раздельных потоков только если единого нет.
- Для фото-постов есть запасной механизм (`PhotoFallback`), разбирающий embed-страницу; сейчас он не работает — Instagram изменил выдачу. Планируется переход на веб-API Instagram с cookies и сборка подборок фото с музыкой в MP4-слайдшоу через ffmpeg.

### Сборка

Требуется Android SDK (compileSdk 36) и JDK 17+ (подойдёт JBR из Android Studio).

```bash
gradlew.bat assembleDebug
```

Debug-APK: `app/build/outputs/apk/debug/app-debug.apk`. Релизный — `gradlew.bat assembleRelease` → `app/build/outputs/apk/release/app-release.apk` (подписывается стандартным debug-ключом Android Studio с вашей машины, см. `app/build.gradle.kts`).

Важно: Gradle должен быть версии 9.5.x — AGP 8.x несовместим с Gradle 9.6+. Wrapper в репозитории уже настроен.

### Ограничения

- Фото-посты и карусели не скачиваются (см. выше).
- APK включает архитектуры arm64-v8a и armeabi-v7a (~98 МБ).
