# InstaD

Android-приложение для скачивания видео (Reels) и фотографий из Instagram на телефон.

## Возможности

- **«Поделиться» из Instagram**: нажмите самолётик → «Поделиться» → InstaD — приложение получит ссылку и сразу начнёт скачивание. Можно и просто вставить ссылку вручную.
- **Видео и фото**: reels и видео-посты качаются через yt-dlp, фото-посты — через запасной механизм.
- **Сохранение в галерею**: всё складывается в `DCIM/InstaD` — в галерее один альбом.
- **Превью и «Мои загрузки»**: после скачивания на экране показывается превью (тап открывает файл в галерее); отдельный экран «Мои загрузки» — сетка всего скачанного, тап — открыть, долгое нажатие — поделиться или удалить.
- **Пересылка**: кнопка «Поделиться» отправляет скачанное в Telegram, WhatsApp или любое другое приложение.
- **Вход в Instagram**: для постов, недоступных без авторизации, встроен вход через WebView — cookies передаются yt-dlp.
- **Автообновление движка**: встроенный yt-dlp обновляется до свежей ночной сборки (не чаще раза в сутки), чтобы переживать изменения на стороне Instagram.

## Как устроено

- Kotlin, одна активити + WebView-экран входа.
- Движок — [youtubedl-android](https://github.com/yausername/youtubedl-android) (yt-dlp + Python, работающие прямо на телефоне), артефакты `library` и `ffmpeg` с Maven Central.
- Фото-посты yt-dlp не поддерживает («No video formats found») — в этом случае `PhotoFallback` разбирает embed-страницу поста. Нюанс: Instagram отдаёт простую серверную разметку только «минимальному» User-Agent без cookies; полноценный браузерный UA получает JS-приложение без данных.

## Сборка

Требуется Android SDK (compileSdk 36) и JDK 17+ (подойдёт JBR из Android Studio).

```bash
gradlew.bat assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Важно: Gradle должен быть версии 9.5.x — AGP 8.x несовместим с Gradle 9.6+.

## Ограничения

- Фото-посты сейчас не скачиваются (Instagram изменил выдачу embed-страницы; при работе через VPN отдаёт JS-оболочку без данных). Планируемое решение — переход на веб-API Instagram с cookies входа; подборки фото с музыкой предполагается собирать в MP4-слайдшоу через ffmpeg для пересылки в мессенджеры.
- Скачивание требует, чтобы трафик приложения проходил через VPN: при split tunneling в VPN-клиенте InstaD должен быть добавлен в список приложений, иначе `[Errno 101] Network is unreachable`.
- Из карусели (пост с несколькими фото) пока скачивается только первая фотография.
- APK включает архитектуры arm64-v8a и armeabi-v7a (~99 МБ).
